# Café Raíz — Punto de venta multisucursal

Interfaz del POS de Café Raíz (React + TypeScript + Tailwind). Las reglas de negocio están en `CLAUDE.md`.

## Comandos

```bash
npm install       # instalar dependencias
npm run dev       # servidor de desarrollo
npm run build     # compilar para producción
npm run preview   # probar la compilación (http://localhost:4173/MVP-CafeRaiz/)
npm run lint      # revisar el código
npm run deploy    # publicar en GitHub Pages (requiere el repositorio remoto)
```

Por ahora la app usa datos de ejemplo (`src/data/`) y un inicio de sesión de demostración.
